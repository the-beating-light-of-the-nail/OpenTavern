## What I do

I manage the project's `TODO.md` file. When asked to record, add, or update a todo item, I:

1. Read the current `TODO.md` from the project root
2. Add the new item under the appropriate section heading
3. Keep items organized and consistently formatted

## When to use me

Use me whenever the user says things like:
- "记一下 todo: ..."
- "记一下 ..."
- "加一条 todo ..."
- "添加一个任务 ..."
- "Add a todo: ..."
- Any request that involves recording a task, idea, or note into the project TODO

## Rules

- Always read `TODO.md` first before editing
- Place items under the most relevant section heading
- If no section fits, add to a "## 其他 / Misc" section
- Use checklist format: `- [ ] ` for pending items, `- [x] ` for completed
- Preserve existing content and formatting
